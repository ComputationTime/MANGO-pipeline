Supported and deferred scope

Source files can exist without being part of the current completion target. This page makes that distinction explicit.

Supported default GPU study

supported The launcher runs one_hot, biopython, esm2, esmif, and proteinmpnn sequentially on one GPU. It trains/evaluates/reconstructs and produces Figures 1, 3, 4, and 5.

Opt-in modules

  • ESM3: gated open model; requires accepted terms and HF_TOKEN.
  • PyRosetta PRE: available through explicit launcher modes; real mmCIF chain mapping still requires validation before scientific use.
  • Boltz-2 and Chai-1 structure confidence: implemented and GPU plumbing-tested, but run through the separate structure_confidence target.

Deferred work

deferred AlphaFold-Multimer, AlphaFold 3 cluster execution/ingestion, therapeutic benchmark antibodies and eight therapeutic complex chains, Figure 2 as a strict supported completion requirement, the Therapeutic Antibody Profiler (TAP), and broader Rosetta post-generation interface analysis are not current milestone requirements.

Why not delete inactive files?

They document planned interfaces and historical work. The active truth is the include list in workflow/Snakefile. Keeping them does not make them completion dependencies, and the nested MANGO Git repository must be preserved.
