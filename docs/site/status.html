Supported and deferred scope

Source files can exist without being part of the current completion target. This page makes that distinction explicit.

Supported default GPU study

supported Plain study runs all seven implemented representations—one_hot, biopython, pyrosetta_pre, esm2, esm3, esmif, and proteinmpnn—sequentially on one GPU. It trains/evaluates/reconstructs, runs the bounded Boltz/Chai structure cohort, applies fixed-backbone Rosetta interface quality control, and produces all required plots. ESM3 access and PyRosetta eligibility are prerequisites.

Default structure-confidence pilot

Boltz-2 and Chai-1 run after generation. Study mode uses three designs from each of ten held-out antigen clusters per model and predictor, with one diffusion draw per design. Smoke and small modes use smaller bounds. Fixed-backbone Rosetta scoring then evaluates the same predicted interfaces without relaxation. This supports variability estimates and paired target-aware analysis, but cannot guarantee a statistically significant result without a prespecified effect size.

Special-dependency modules

  • ESM3: included in study but gated; requires accepted terms and HF_TOKEN.
  • PyRosetta PRE antigen embedding: included in study and distinct from default Rosetta interface analysis; real SAbDab mmCIF chain mapping must be validated with smoke-all before scientific interpretation.

Deferred work

deferred AlphaFold-Multimer, AlphaFold 3 cluster execution/ingestion, therapeutic benchmark antibodies and eight therapeutic complex chains, the Therapeutic Antibody Profiler (TAP), and broader Rosetta post-generation interface analysis are not current milestone requirements.

Why not delete inactive files?

They document planned interfaces and historical work. The active truth is the include list in workflow/Snakefile. Keeping them does not make them completion dependencies, and the nested MANGO Git repository must be preserved.
