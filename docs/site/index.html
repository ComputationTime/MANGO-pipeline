MANGO, explained from the beginning

MANGO is an experimental pipeline for asking how the way we describe an antigen changes a model’s ability to generate an antibody heavy chain when the antigen and matching light chain are provided.

The invariant task: every trained model receives an antigen representation and a light-chain representation. It must produce the heavy-chain variable sequence. The true heavy chain is never part of the conditioning input.

What problem is this project studying?

An antibody recognizes a molecular target called an antigen. An antibody usually contains paired heavy and light protein chains. Their three-dimensional arrangement and amino-acid sequences jointly determine recognition. MANGO fixes the light chain, varies how the antigen is encoded, and asks the model to generate the corresponding heavy chain. This isolates one experimental variable: the antigen representation.

Antigen structure or sequence+cognate light chain→MANGO model→generated heavy chain

Where the code lives

workflow/Snakefile includes the active rule modules. workflow/rules/ describes dependencies and outputs. workflow/scripts/ performs scientific computation. workflow/envs/ isolates incompatible software. config/ selects experimental settings. Generated data, model weights, caches, and results stay under artifacts/ or .snakemake/ and are not committed.
