Glossary

Compact definitions for biological, machine-learning, structural, and workflow terms used in this guide.

TermDefinition in this project
AbLang2A pretrained antibody language model. MANGO uses it both to encode the light-only conditioning context and, separately, as an independent generated-sequence scorer.
AF3AlphaFold 3. Future structure-prediction execution/ingestion is deferred to the cluster.
AF-MAlphaFold-Multimer. Its antigen/light representation is a deferred stub.
Amino acidA chemical building block of proteins; sequences use one-letter residue codes.
ANARCISoftware that numbers antibody variable domains and assigns likely germline genes.
APIApplication Programming Interface: the documented functions or commands through which one software component calls another.
AntibodyA recognition protein composed of paired heavy and light chains; variable domains form much of the binding surface.
AntigenThe target molecule recognized by an antibody. This study is configured for protein antigens.
Autoregressive modelA model that predicts a sequence one token at a time, using earlier tokens and conditioning context.
Boltz-2An open biomolecular structure predictor used here for bounded default H+L+antigen complex confidence.
CDR3Complementarity-determining region 3, a highly variable loop important for recognition. MANGO’s target is broader than CDR3: the resolved heavy variable sequence.
Chai-1An open biomolecular structure predictor used alongside Boltz-2.
Checkpoint (model)A saved set of learned model parameters, such as best.pt.
Checkpoint (Snakemake)A workflow rule that must run before the system can determine later jobs dynamically.
CognateNaturally paired in the recorded complex; for example, the light chain observed with a target antigen.
Conda environmentAn isolated collection of exact software dependencies for a rule.
CPUCentral processing unit, the computer's general-purpose processor.
Cross-attentionA neural-network operation allowing generated heavy-chain states to use antigen and light-context features.
CSVComma-separated values, a plain-text table format used for records, designs, metrics, and plot source data.
CUDANVIDIA’s platform for GPU computation.
DAGDirected acyclic graph: the file dependency graph Snakemake constructs.
Data leakageInformation unavailable at genuine prediction time entering training, model selection, or input conditioning.
Diffusion sampleOne candidate three-dimensional structure sampled by a diffusion-based structure predictor.
EmbeddingA numeric matrix representing residues and their context or structure.
ESMEvolutionary Scale Modeling, a family of pretrained protein models.
ESM-IFESM Inverse Folding, a structure-conditioned protein model used as an antigen encoder.
FASTAA plain-text format containing a header followed by a biological sequence.
GermlineAn inherited antibody gene template before rearrangement/mutation in a mature antibody lineage.
GPUGraphics processing unit, hardware used to accelerate tensor calculations.
GRAVYGrand Average of Hydropathy, the mean residue hydropathy of a sequence.
Heavy chain (H)The antibody chain generated by MANGO. The target is the processed resolved variable-region sequence.
ipTMInterface predicted Template Modeling score, a predicted confidence measure for relative chain placement.
JSONJavaScript Object Notation, a structured text format used for configuration snapshots, metrics, markers, and reports.
Light chain (L)The observed antibody partner supplied as fixed conditioning context.
Levenshtein distanceMinimum insertions, deletions, and substitutions required to transform one string into another.
mmCIFMacromolecular Crystallographic Information File, a structured text format for biomolecular coordinates and metadata.
MSAMultiple-sequence alignment, an alignment of related sequences that can provide evolutionary information.
NLLNegative log-likelihood. Lower values mean the model assigned more probability to observed target tokens.
PAEPredicted aligned error, a structure model’s estimate of relative positional uncertainty.
PDBProtein Data Bank; also used for four-character structure identifiers.
PerplexityThe exponential of mean NLL, a probability-model uncertainty summary; lower is better.
pLDDTPredicted Local Distance Difference Test score, a local structure-confidence estimate.
PNGPortable Network Graphics, the raster image format used for figures and training curves.
ProteinMPNNA pretrained structure-conditioned protein sequence model; MANGO uses internal antigen representations from it.
pTMPredicted Template Modeling score, a global structure-confidence estimate.
PyRosetta PREPyRosetta per-residue energy antigen representation. PRE here does not mean a post-generation Rosetta interface screen.
RCSBResearch Collaboratory for Structural Bioinformatics, which operates major Protein Data Bank services.
ReconstructionGenerating a heavy chain for a held-out example whose true heavy sequence is known for comparison.
ResidueAn amino acid as incorporated into a protein chain.
SAbDab2The versioned structural antibody dataset used by the pipeline.
SnakemakeWorkflow software that runs rules based on file dependencies.
SHA-1 / SHA-256Secure Hash Algorithms used here to derive stable configuration identities and deterministic selection ranks, not to protect passwords.
TAPTherapeutic Antibody Profiler, a deferred analysis not approximated by the current simple developability module.
TokenA discrete model symbol, such as an amino-acid code or begin/end marker.
Train/validation/testDisjoint data roles: parameter fitting, checkpoint selection, and final held-out evaluation.
URL / HTTPSA Uniform Resource Locator identifies a network resource; Hypertext Transfer Protocol Secure is the encrypted transfer protocol used for downloads.
WildcardA variable path component in a Snakemake rule, such as {run}.
YAMLA human-readable structured configuration format used by environments, project configuration, and Boltz inputs.
