Concepts from first principles

This page defines the ideas used throughout the rest of the guide. Later pages link back here, but each module page also repeats the definitions essential to that module.

Proteins, sequences, and structures

A protein is a chain of smaller chemical units called amino acids. Biology commonly uses twenty standard amino acids. A protein sequence writes them as one-letter symbols, such as EVQLV.... Sequence order matters: changing even one residue can change folding or binding. A protein structure gives three-dimensional coordinates for atoms. MANGO uses macromolecular Crystallographic Information File (mmCIF) structures when an encoder needs geometry.

Antibodies and antigens

An antigen is the target molecule recognized by an antibody. In this study antigens are proteins. A conventional antibody contains two kinds of protein chain: heavy and light. The variable domains of these chains form the recognition surface. MANGO’s output is the structurally resolved heavy-chain variable-region sequence available in SAbDab2—not merely the third complementarity-determining region (CDR3), and not necessarily an entire full-length antibody molecule including every constant-domain residue.

Cognate means naturally paired in the observed complex. “Cognate light chain” therefore means the light chain observed with that antigen and heavy chain in the same structure.

Representations and embeddings

A neural network cannot directly consume a chemical idea such as “this antigen.” It consumes numbers. A representation is a rule for turning the antigen into numbers. An embedding is the resulting numerical array, usually a matrix with one row per residue and several numeric features per row. One-hot encoding records residue identity directly; protein language models produce learned contextual features; structure-based methods include geometric information.

Training, validation, and testing

During training, the model sees examples and changes its parameters to reduce prediction error. The validation split is not used to fit individual gradient steps; it helps select the best checkpoint and decide when training should stop. The test split is held back until evaluation. A fair test must not contain close groups that also appear in training.

Data leakage occurs when information that should be unknown at prediction time enters training or conditioning. MANGO prevents two major forms: the true heavy chain is masked from the input, and antibody–antigen clusters cannot cross train, validation, and test boundaries.

Clusters and diversity

A cluster groups related antibody–antigen examples. If nearly identical complexes appeared in both training and test data, good scores could reflect memorization. MANGO splits by ab_ag_cluster, not by individual row. Generation then selects one representative from every held-out test cluster before any optional cap is applied. This gives broad antigen-cluster coverage rather than a hand-picked set of eight examples.

Language modeling and likelihood

MANGO generates a heavy sequence one token at a time. A token is a model symbol, usually an amino-acid letter plus special begin/end markers. At each position the model assigns probabilities to possible next tokens. The negative logarithm of the probability assigned to the correct token is a loss. Averaging this gives negative log-likelihood (NLL); lower is better. Perplexity is the exponential of mean NLL and can be read loosely as model uncertainty; lower is also better.

Reconstruction versus de novo generation

Held-out reconstruction asks the model to generate for a test example whose true heavy chain is known, allowing sequence recovery measurements. De novo generation samples many possible heavy chains from the learned distribution for antigen + light context. The model is not handed a heavy prefix under the default generation contract.

Snakemake and the directed acyclic graph

Snakemake is workflow software. A rule names input files, output files, parameters, software environment, and the script that performs work. Snakemake builds a directed acyclic graph (DAG): files create arrows from prerequisites to downstream products, and “acyclic” means dependencies never loop backward. A wildcard, such as {run}, lets one rule create many related jobs. A checkpoint is a rule whose output must be read before Snakemake can know how many later jobs exist.

Conda environments and graphics processors

A Conda environment is an isolated set of software versions. This project isolates embedders because packages can require incompatible versions. A graphics processing unit (GPU) accelerates tensor operations. Rules declaring gpu=1 are serialized by the one-GPU profile so two large models do not compete for the same card.
