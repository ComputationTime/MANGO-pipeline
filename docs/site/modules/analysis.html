Modules / Analysis

Analysis as independent, inspectable stages

Generated sequences are selected once, scored by separate tools, and plotted from saved tables. This separation avoids hiding scientific calculations inside plotting code.

Shared cohort principle

Figures 3–5 use a deterministic cohort chosen from successful generated designs. Each model receives the same target coverage and the same requested number per target. The selection key depends on seed, target, and design index rather than CSV row order. Each scorer reads that same cohort, so differences between panels are not caused by silently changing examples.

Status fields are data

Scorers preserve status columns rather than silently dropping failures. Plotters filter to successful/finite metrics, while source CSVs make the filtering auditable. A sequence rejected by ANARCI or a failed external scorer is qualitatively different from a measured poor score.

Independent tools reduce circularity

MANGO’s own probability is not the only downstream measure. Independent antibody language models, germline assignment, and physicochemical calculations provide complementary views. They still remain computational proxies and can share biases with training data, so no single metric is definitive.

Legacy boundary

The old combined workflow/rules/analysis.smk and its older generic scripts remain in the tree for historical context but are not included by the active Snakefile. The active workflow uses the smaller files under workflow/rules/analysis/.
