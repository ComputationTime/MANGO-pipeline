Analysis / structure_confidence.smk

Fold generated complexes with Boltz-2 and Chai-1

This bounded default module predicts three-dimensional complexes containing a generated heavy chain, its cognate light chain, and every antigen chain, then converts predictor-specific outputs into one table format.

Default sampling: study mode folds three generations from each of ten independently held-out antigen clusters per model and predictor. Small mode uses four targets × two designs; smoke uses one target × one design. AlphaFold 3 (AF3) remains deferred to cluster execution/ingestion.

Shared input construction

  1. Read successful rows from the model/target designs.csv.
  2. Rank designs deterministically from seed, target, and design index; take the configured small subset.
  3. Read exactly one target record and obtain the resolved light sequence plus all antigen sequence segments.
  4. Validate canonical amino acids.
  5. Create chains in order: generated heavy H, light L, then AG1, AG2, and so on.

Rule: predict_boltz_confidence

The script writes one YAML input per design and invokes one Boltz batch so weights are loaded once. By default every protein has msa: empty, meaning no multiple-sequence alignment (MSA). If the external MSA server is explicitly enabled, that marker is removed and the Boltz flag is added. Boltz writes mmCIF structures, confidence JSON, and full predicted aligned error arrays.

Rule: predict_chai_confidence

The script writes protein FASTA records for H, L, and antigen chains, imports Chai once, and processes selected designs in one Python process so cached components are reused. It records per-design errors and fails only after writing diagnostics if every design failed. Chai is isolated in its own environment; a post-deploy script upgrades PyTorch to a CUDA 12.8 build that supports Blackwell GPUs.

Diffusion samples and plotting

Structure predictors can generate several candidate structures for one sequence. The normalized table stores one row per sample. The Figure 2 plotter first selects the sample with the highest predictor-specific confidence_score for each embedder/target/design/predictor combination, preventing multiple samples from being treated as independent sequences.

Validated plumbing behavior

A two-sequence GPU plumbing check confirmed sequence → Boltz/Chai CIF → normalized confidence → plot. It also established compatibility with Boltz’s nested boltz_results_* batch layout and Chai 0.6.1’s released API. Those smoke sequences were truncated, so their numeric confidence is not scientifically interpretable.

Interpretation limits

Prediction confidence is not binding affinity. A confident complex may still be biologically wrong, and low confidence can reflect missing evolutionary context. Boltz and Chai scores should be compared within predictor, with target identity retained. Future Rosetta interface energy analysis could add an orthogonal structural plausibility filter, but it is not yet this module’s contract.
