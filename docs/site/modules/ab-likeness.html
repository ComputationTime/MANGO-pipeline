Analysis / ab_likeness.smk

Score generations with independent antibody language models

An antibody language model learns statistical patterns in antibody sequences. These scorers ask whether generated heavy chains resemble patterns learned independently of MANGO.

Three separate rules

RuleTool and measureEnvironment
analysis_score_iglmIgLM sequence log-likelihood using configured heavy-chain and species control tokens.analysis_iglm.yaml
analysis_score_antibertyAntiBERTy pseudo-log-likelihood, obtained by masking residues and asking the model to recover them.analysis_antiberty.yaml
analysis_score_ablang2AbLang2 confidence in the configured scoring mode, using the project’s cached paired weights.analysis_ablang2.yaml

Shared contract

Input: one run’s deterministic cohort.csv.

Outputs: metrics/iglm.csv, metrics/antiberty.csv, and metrics/ablang2.csv.

Resources: each scorer requests one GPU and 16 GB memory; the single-GPU profile serializes them.

Why independent environments?

The packages require different versions of PyTorch and related libraries. Separate environments prevent one scorer’s dependencies from changing another’s behavior. They also make a failed optional scorer local: generated sequences and other metrics remain usable.

Scores are not interchangeable

Each tool uses a different architecture, training corpus, tokenization, and mathematical score. Figure 3 gives each scorer its own panel/axis. Do not subtract an IgLM value from an AntiBERTy value or interpret equal numeric values as equal plausibility.

Status and provenance

Each output carries the original design identifiers and tool-specific status. Invalid sequences or model failures are recorded, not converted to arbitrary numbers. Parameters such as IgLM species/chain tokens and AbLang2 mode are saved as columns.

Interpretation limits

A favorable language-model score means a sequence resembles the model’s learned antibody distribution. It does not prove correct folding, antigen binding, low immunogenicity, or manufacturing suitability. Similar training corpora can also create correlated biases among scorers.
