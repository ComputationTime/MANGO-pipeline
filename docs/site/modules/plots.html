Analysis / plots.smk

Turn metric tables into figures

Plotting rules perform presentation and controlled filtering, not expensive biological inference. Every image has a companion CSV containing the rows used to draw it.

Shared plotting contract

Inputs: evaluation JSON or metric CSV files for all configured analysis embedders.

Outputs: artifacts/analysis/figures/<name>.<format> and <name>_data.csv.

Environment: analysis_plot.yaml.

Parameters: ordered embedder tags, human-readable labels, image dots per inch, and relevant method names.

Shared visual conventions

plot_common.py supplies consistent colors, labels, legends, axis styling, empty-panel messages, and file saving. Embedder order comes from configuration, not arbitrary CSV ordering. The image format and resolution also come from configuration.

Why save source data?

A figure is a lossy representation. The source CSV permits exact auditing, alternative statistical analysis, and regeneration without rerunning GPU scorers. It also reveals how failed/nonfinite rows were handled.

Figure 2 sample selection

For each generated design and predictor, the script converts scores to numeric values, keeps successful rows, and chooses the diffusion sample with maximum ranking confidence. Boxplots then summarize designs, not diffusion replicates.

Empty panels

A missing metric should not create a misleading zero. Plot helpers display an explanatory “no data” panel. Upstream strict completion still decides whether a full cross-embedder figure set is trustworthy.
