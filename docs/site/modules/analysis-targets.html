Named completion targets for analysis

Aggregate rules contain no scripts. They group lower-level outputs into convenient command-line goals.

Rule: analysis_metrics

Requires IgLM, AntiBERTy, AbLang2, germline, and biophysical CSV files for every analysis embedder. It is useful when metric tables are needed but cross-model figures are not.

Rule: figures

Requires image and source-data CSV outputs for each figure whose enabled setting is true. Figures 1–5 are enabled in the ordinary configuration; Figure 2 uses the bounded structure-confidence subset.

Rule: analysis

Aliases the figures inputs. Running snakemake ... analysis therefore asks Snakemake to trace backward through plot inputs, metric rules, cohorts, generation, model outputs, and embeddings as needed.

Separate structure target

structure_confidence remains directly addressable and explicitly requires normalized Boltz/Chai scores plus Figure 2. The GPU launcher also requests per-run structure completion by default, so strict completion includes the bounded structural layer.

Why aggregation is safe

These rules do not copy or summarize data. They merely declare that a named goal is complete when its input files exist and are up to date. Scientific computation remains in the specific module that owns it.
