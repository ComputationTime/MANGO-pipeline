Modules / common.smk

Shared registry, paths, and safeguards

workflow/rules/common.smk creates no jobs. It translates configuration into consistent names and helper functions used by every other module.

Module contract

Reads: the merged Snakemake configuration and, after the processing checkpoint, records.csv.

Provides: constants, validated registries, path-building functions, run hashes, target lists, wildcard constraints, and split-aware dependency lists.

Why centralize paths?

If each rule independently constructed filenames, two rules could disagree about where an embedding or checkpoint belongs. Common helpers make the filename itself part of the interface. For example, antigen_emb_path(tag, split, instance) always resolves to the same per-record tensor location.

Configuration validation

The module confirms that every active embedder tag exists in the registry. It maps a tag such as esm2 to its method, parameters, and display label. Most importantly, it rejects any antibody context other than light_only. This makes the antigen + light → heavy task a parse-time invariant rather than a convention left to individual scripts.

Checkpoint-dependent expansion

_records_df() calls checkpoints.process_records.get(). Snakemake first executes processing, then the helper reads the finished table. instances_by_split() converts its rows into (split, id) pairs, and embedding helpers turn those pairs into exact expected output paths.

Fine-grained and batch dependency modes

In ordinary mode a downstream rule depends on every per-record tensor. In GPU batch mode it depends on a .batch_complete.json marker. The batch script writes the same individual tensors before writing the marker, so model code sees identical files in both modes.

Experiment hash

experiment_hash(tag) serializes the scientifically meaningful configuration in stable key order and computes a short SHA-1 hash. The run identifier becomes, for example, esm2__e37a6a17. Dataset choice, filtering, embeddings, model hyperparameters, weights, and seed affect identity. Whether to retrain and how often to refresh a plot do not.

Diverse generation targets

generation_instances() delegates to select_generation_targets. For the normal test source, the strategy is one representative per held-out antibody–antigen cluster, followed by an optional maximum. Selection is deterministic, so all models generate against the same target identifiers. This is the key connection between leakage-safe processing and broad downstream figures.

Wildcard hygiene

A wildcard is a variable part of a path. Constraints prevent a wildcard from consuming unintended text: splits are limited to train|val|test|target, run names are limited to computed active run identifiers, and embedder names are limited to registered tags. Method-specific embedding rules use even narrower constraints so multiple rules with the same output pattern are not ambiguous.

Common mistakes this module prevents

  • Activating an unknown embedder.
  • Conditioning on an unmasked heavy chain.
  • Mixing outputs from incompatible scientific configurations.
  • Expanding record-dependent jobs before processing finishes.
  • Generating from a split that was not embedded.
  • Requesting unsupported local structure predictors such as deferred AF3.
