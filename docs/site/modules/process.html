Modules / process.smk

Filter records, resolve sequences, and assign splits

Processing creates the single authoritative table consumed by embeddings, model code, target selection, and analysis.

Checkpoint: process_records

Input: standardized.csv.

Output: processed/records.csv.

Parameters: the complete processing configuration block.

Script: process_records.py; environment process.yaml.

Why this is a checkpoint

Filtering changes which identifiers remain. Snakemake cannot construct one embedding job per kept record until this table exists. A checkpoint pauses graph expansion, runs processing, and then lets common helper functions inspect the result.

Filtering

The configured production cohort requires paired heavy and light chains, protein antigens, existing structure files, and a maximum summed resolved antigen length. Smoke mode enables a tiny cluster-preserving subset, but those metrics only test plumbing.

Resolved sequences

Experimental structures may omit flexible or poorly resolved residues. The mmCIF helper reads backbone-complete residues. resolved_H_seq, resolved_L_seq, and resolved_ag_seq therefore describe the residues represented by structure-based encoders. Multiple antigen chains are retained as comma-separated segments rather than silently concatenated without boundaries.

When reliable resolved sequences are already supplied by the standardizer, processing uses them; otherwise it parses the structure. The chosen embedding sequence source is configured globally so sequence and structure representations stay comparable.

Cluster-aware validation

  1. Read the source train/test assignment.
  2. Verify that the configured cluster column exists and is nonblank.
  3. Verify that a source-test cluster does not also appear in source training.
  4. Deterministically choose a fraction of source-training clusters for validation using the configured seed.
  5. Assign every row in a chosen cluster to validation; all remaining source-training clusters remain training.
  6. Verify no cluster crosses train, validation, or test.
Leakage guarantee: the split unit is the antibody–antigen cluster, never an individual row. This guarantee propagates into diverse generation because targets are later selected from held-out test clusters.

Failure is preferable to silent fallback

The module fails on missing cluster information, cluster overlap, required missing structures, or inability to obtain essential sequences. It does not replace cluster splitting with row-wise random splitting and does not invent sequences.
