Snakemake module directory

A module is a .smk file included by the top-level Snakefile. It groups related rules but does not itself create a separate process. Snakemake combines all included rules into one dependency graph.

Core data and model modules

common.smk

Validates configuration, derives paths, computes run hashes, reads checkpoint results, and selects held-out generation targets. It defines no jobs.

fetch.smk

Downloads and stages the versioned SAbDab2 archive.

standardize.smk

Converts dataset-specific metadata into a stable table contract.

process.smk

Filters records, resolves sequences, and creates cluster-aware splits.

embed.smk

Builds antigen tensors and constant masked-heavy/light-chain context tensors.

model.smk

Trains, evaluates, reconstructs, and generates heavy sequences.

Analysis modules

The analysis directory deliberately separates cohort selection, each scientific metric, and plotting. This makes failures local and preserves intermediate tables.

cohorts.smk

Chooses comparable generated sequences deterministically.

likelihood.smk

Exposes evaluation JSON files for Figure 1.

ab_likeness.smk

Runs IgLM, AntiBERTy, and AbLang2 independent scorers.

germline.smk

Assigns nearest germline genes with ANARCI and measures sequence distance.

developability.smk

Computes hydropathy and estimated charge.

structure_confidence.smk

Opt-in Boltz-2/Chai-1 complex prediction and confidence normalization.

plots.smk

Turns metric tables into Figures 1–5 and source-data CSV files.

analysis/targets.smk

Defines explicit aggregate targets for metrics, figures, and analysis.

Cloud execution

gpu.smk checks the hardware, gathers strict outputs, and always writes a partial report. The shell launcher adds the crucial behavior of running embedders in separate Snakemake invocations.

Not active: workflow/rules/analysis.smk is an older combined analysis implementation and is not included by workflow/Snakefile. workflow/rules/targets.smk describes deferred therapeutic targets and is also not included. See scope and status.
