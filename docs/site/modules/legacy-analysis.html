Scope / analysis.smk

Legacy combined analysis module

Inactive: workflow/rules/analysis.smk is not included by workflow/Snakefile. The modular files under workflow/rules/analysis/ are authoritative.

This older file grouped sequence metrics, structure prediction, complex metrics, plotting, and aggregate targets into a single generic interface.

Why modularization is better here

Each scientific tool now owns a separate environment, log, status table, and rule. A failed scorer does not obscure other outputs. Explicit plot inputs document exactly which tables feed a figure. Structure confidence no longer uses a placeholder predictor interface.

How to avoid confusion

Do not edit or invoke historical rules expecting the active graph to change. Start at the top-level Snakefile’s include list. If a legacy capability is revived, port it into a tested active module rather than including both files and creating duplicate rule names.
