Scope / targets.smk

Deferred therapeutic-target rules

Inactive: workflow/rules/targets.smk is present but not included by the top-level Snakefile. None of these rules belongs to the current supported completion target.

The intended design adapts external therapeutic complexes into the same records-shaped interface used by ordinary test structures.

Rule: fetch_target_structure

Would download one mmCIF structure per configured Protein Data Bank (PDB) identifier from the Research Collaboratory for Structural Bioinformatics (RCSB) base URL and store it under artifacts/targets/structures.

Rule: standardize_targets

Would read all downloaded complexes plus configured chain definitions and write targets_records.csv with split=target. The records-shaped table is the important design decision: existing embedding rules can then write tensors beneath a target/ split without new scientific encoders.

Aggregate targets

targets would require the standardized target table. embed_targets would require every active antigen embedding for every configured PDB target.

Why it remains deferred

The therapeutic antibody list, exact complex chains, leakage/benchmark policy, and scientific validation have intentionally been excluded from the current milestone. In addition, active common logic rejects generation.source=target unless that split is enabled, preventing accidental use.

What must happen before activation

  • Validate every PDB and heavy/light/antigen chain mapping.
  • Demonstrate that targets are absent from training and define similarity exclusions.
  • Define expected resolved-sequence behavior for missing residues.
  • Add the module to the Snakefile only after tests and completion semantics are agreed.
