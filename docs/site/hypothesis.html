Hypothesis and experimental design

MANGO is a controlled comparison of antigen representations, not a collection of unrelated models.

The hypothesis

Working hypothesis: richer representations of antigen sequence, biochemical properties, or three-dimensional structure provide information that improves conditional heavy-chain modeling and generation compared with a simple residue-identity baseline.

The project tests whether the representation changes: (1) held-out heavy-chain likelihood, (2) the antibody-like character of generated sequences, (3) distance to assigned germline sequences, (4) simple developability properties, and (5) predicted complex confidence on a bounded structural subset.

What changes, and what stays fixed?

ComponentExperimental treatment
Antigen representationChanges. This is the independent variable: one-hot, BioPython descriptors, ESM-2, ESM Inverse Folding, ProteinMPNN, and opt-in methods.
Light-chain contextFixed. Every model uses the same AbLang2 light-only embedding with the heavy slot masked.
MANGO architecture and hyperparametersFixed. The same decoder/cross-attention design is trained for every antigen representation.
Dataset and splitFixed. Models see the same processed records and cluster-aware split.
Generation targets and sampling settingsFixed. Each model generates against the same diverse held-out target set using the same requested number, temperature, and length rules.

Why the heavy chain cannot enter the input

The target of prediction is the heavy-chain sequence. If the true heavy chain or a feature computed from it appeared in the conditioning inputs, the model could copy information it is supposed to predict. The antibody embedder therefore runs AbLang2 on a masked-heavy paired format conceptually written as *|L, where * is the masked heavy slot and L is the light sequence. The saved directory name includes light_only to prevent accidental reuse of an embedding made for a different task.

Why split by antibody–antigen cluster?

Randomly assigning rows would allow related complexes to cross splits. MANGO instead groups by ab_ag_cluster. Entire groups are assigned together. Validation is carved from source-training clusters, while source-test clusters remain test. Processing fails when cluster information is missing, blank, or overlaps splits.

What would support the hypothesis?

Evidence would be a consistent improvement over one-hot encoding across held-out clusters and multiple complementary metrics, without changing the context, targets, architecture, or sampling protocol. One favorable plot is insufficient. Results should be considered by target cluster, because an average can be dominated by easier antigens.

What the experiment cannot establish alone

It cannot prove laboratory binding, therapeutic safety, or clinical usefulness. Predicted structure confidence, language-model scores, and physicochemical descriptors are computational filters. Experimental validation and more specialized structural/biophysical analyses would be required for biological claims.
